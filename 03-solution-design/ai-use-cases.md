# AI Use Cases

## Appropriate Uses

- Semantic search across approved policy content
- Summarizing relevant policy language
- Answering routine questions from retrieved context
- Classifying a request for downstream workflow routing
- Drafting a response for human review

## Uses Requiring Human Control

- Employment decisions
- Policy exceptions or waivers
- Legal interpretations
- Questions with conflicting policy sources
- Questions for which adequate supporting content cannot be retrieved
- Changes to official policy
