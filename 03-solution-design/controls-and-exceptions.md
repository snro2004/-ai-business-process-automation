# Controls and limitations

Implemented controls: required form fields; restricted request-type dropdown; fixed policy key; citations and unsupported-answer instructions; refusal to approve; deterministic reviewer assignment; Pending review status; confirmation explicitly says NOT approved; no agent write tools; no pinned data in exports.

Limitations: prompt instructions are not a formal guarantee; no authentication on forms; no empty-text guard or OCR; no request deduplication; unknown request types default to Manager; no notifications, reviewer identity lookup, authorization, approval interface, audit policy, or retention automation; chat and form are separate. These are future hardening tasks, not completed features.

Use only the fictional policy and test employee names. An actual HR deployment requires controls appropriate to its environment and independent verification of policy interpretation.
