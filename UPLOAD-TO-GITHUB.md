# Upload to the existing repository

Repository: https://github.com/snro2004/-ai-business-process-automation

1. Unzip this package on the Mac.
2. Open the repository and choose Add file → Upload files.
3. Drag the contents INSIDE ai-business-process-automation into the upload area. Do not add an extra enclosing folder.
4. Commit with message: Document tested PTO workflows and add sanitized exports.
5. Delete the old `workflow/rag-policy-assistant.sanitized.json` from GitHub; it was an architecture sketch, not a runnable export, and is replaced by three actual workflow templates.
6. Confirm the root README shows the new Data Table architecture and workflow contains the three numbered JSON files.

The package replaces the existing documentation at matching paths. Upload is not completed by downloading this archive. The current GitHub connector previously rejected writes, so use this browser upload path.
